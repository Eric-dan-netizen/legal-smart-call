# 法律行业外呼话术脚本

> 专业 · 合规 · 高转化

---

## 一、话术设计原则

1. **前 10 秒定生死** - 开场白必须说清"你是谁 + 为什么打 + 对他有什么好处"
2. **不承诺结果** - 法律禁止承诺胜诉，只能说"分析案情/评估方案"
3. **给退路** - 每次邀约都给"考虑一下"的空间，避免骚扰感
4. **合规第一** - 不冒充公检法、不恐吓、不虚假宣传

---

## 二、标准话术流程

### 版本 A：离婚纠纷邀约

#### 【开场白 - 15 秒】
```
"您好，请问是张先生/女士吗？
这里是 XX 律师事务所的案件回访中心。
看到您之前咨询过离婚相关的法律问题，
我们这边安排了专业婚姻家事律师，
可以免费帮您做一个案情分析和权益评估。
大概占用您 2 分钟时间，您现在方便吗？"
```

#### 【客户回应处理】
- ✅ "方便/你说" → 进入【案情确认】
- ⏸ "在忙/稍后" → 进入【预约回电】
- ❌ "不需要/没兴趣" → 进入【礼貌结束】

#### 【案情确认 - 30 秒】
```
"好的，简单跟您确认一下：
您目前是想咨询协议离婚还是诉讼离婚呢？
...（客户回答）
那您这边有涉及财产分割或者孩子抚养权的问题吗？
...（客户回答）
明白，那这类情况我们律师处理过很多类似案例，
可以帮您评估一下最有利的方案。"
```

#### 【邀约到店 - 20 秒】
```
"您看这周或者下周，哪天方便来我们律所坐一下？
律师面对面帮您分析，也能看看您手头的材料。
我们在【XX 区 XX 路 XX 大厦】，地铁 X 号线直达。
周三下午或者周六上午，您哪个时间方便？"
```

#### 【降低门槛 - 15 秒】（客户犹豫时使用）
```
"没关系，您不用现在就决定。
我先加一下您微信，把律所位置和我们准备的一些资料发您，
您先看看，有需要随时联系我。
这个手机号就是您微信吗？"
```

#### 【结束确认 - 10 秒】
```
"好的，那稍后我让助理加您微信，
您注意通过一下。
有任何问题随时联系我，祝您生活愉快，再见！"
```

## 三、客户回应应对话术

| 客户说 | 应对话术 |
|--------|----------|
| "我不需要" | "明白，那我先不打扰您。如果后续有需要，可以随时联系我们。祝您生活愉快，再见。" |
| "你们怎么有我电话？" | "您之前在我们的官网/公众号咨询过，我们这边是案件回访。如果您不希望再接到电话，我可以帮您登记不再联系。" |
| "律师费多少钱？" | "费用要看具体案情，我们第一次咨询是免费的。律师了解完您的情况后会给您一个明确的报价，您觉得合适再合作。" |
| "我自己能处理" | "当然可以，简单的情况自己处理没问题。但如果涉及财产分割/赔偿金额较大，建议还是让律师帮您把关一下，至少知道您的权益有哪些。" |
| "我再考虑一下" | "没问题，这种大事确实要考虑。我先加您微信，发一些资料给您参考，您有任何问题随时问我。" |
| "在忙/开会" | "好的好的，那您先忙。我下午 3 点左右再给您打过来，或者您方便的时候给我回个电话也可以。" |

## 五、录音制作建议

### 录音要求
- **语速**：正常偏慢，约 200 字/分钟
- **语调**：专业、温和、有亲和力
- **配音**：建议找专业女声（信任度更高）
- **格式**：MP3，128kbps，单声道即可

### 录音文件命名
```
script_divorce_opening.mp3      # 离婚纠纷 - 开场白
script_divorce_confirmation.mp3 # 离婚纠纷 - 案情确认
script_divorce_invite.mp3       # 离婚纠纷 - 邀约到店
script_divorce_close.mp3        # 离婚纠纷 - 结束确认

script_debt_opening.mp3         # 债务纠纷 - 开场白
script_accident_opening.mp3     # 交通事故 - 开场白

response_not_needed.mp3         # 通用 - 不需要
response_busy.mp3               # 通用 - 在忙
response_consider.mp3           # 通用 - 考虑一下
```

## 六、合规注意事项

⚠️ **禁止内容**
- ❌ "保证胜诉"、"100% 拿到赔偿"
- ❌ "我们是法院合作的"、"法官认识"
- ❌ "不找律师就输了"、"对方已经请律师了"
- ❌ 冒充公检法、政府部门

✅ **推荐表述**
- "帮您分析案情"、"评估可行性"
- "我们处理过类似案例"
- "建议您咨询专业律师"
- "第一次咨询免费"

## 七、数据优化建议

每周复盘以下数据，优化话术：

| 指标 | 计算方式 | 健康值 |
|------|----------|--------|
| 接通率 | 接通数/外呼数 | >60% |
| 意向率 | 意向客户/接通数 | >20% |
| 加微信率 | 微信数/意向客户 | >50% |
| 到店率 | 到店数/微信数 | >30% |

**优化方向：**
- 接通率低 → 调整外呼时间（上午 10-11 点，下午 3-5 点）
- 意向率低 → 优化开场白前 10 秒
- 加微信率低 → 强化"给资料"的价值
- 到店率低 → 增加跟进频次 + 限时优惠
