# 法律行业外呼系统 - 合规检查清单

> ⚠️ **重要提示**：本清单仅供参考，不构成法律意见。建议聘请专业律师审查业务流程。

---

## 一、个人信息保护法合规

### 1.1 客户信息收集 ✅

- [ ] **合法来源**：确保客户信息来自合法渠道（官网咨询、公众号留言、线下活动等）
- [ ] **明示目的**：收集时告知客户信息用途（"用于法律服务回访"）
- [ ] **最小必要**：仅收集必要信息（姓名、电话、案件类型），不收集无关信息
- [ ] **同意记录**：保留客户同意联系的证据（表单勾选记录、聊天截图等）

### 1.2 信息存储安全 ✅

- [ ] **加密存储**：手机号等敏感信息加密存储（系统已实现 AES 加密）
- [ ] **访问控制**：仅授权人员可访问客户信息（系统已实现 RBAC 权限）
- [ ] **传输加密**：使用 HTTPS 传输数据
- [ ] **备份机制**：定期备份数据，防止丢失

### 1.3 信息使用规范 ✅

- [ ] **用途限制**：仅用于约定的法律服务，不用于其他商业目的
- [ ] **不对外提供**：不向第三方出售或提供客户信息
- [ ] **留存期限**：客户信息留存不超过必要期限（建议 2 年）
- [ ] **删除机制**：客户可要求删除其信息（系统需提供删除功能）

---

## 二、通信外呼合规

### 2.1 外呼行为规范 ✅

- [ ] **呼叫时间**：仅在合理时间外呼（8:00-21:00），避免休息时间
- [ ] **呼叫频率**：同一号码每周≤3 次，避免骚扰
- [ ] **身份明示**：开场白明确告知律所名称和来电目的
- [ ] **不冒充**：不冒充公检法、政府部门、法院等

### 2.2 退订机制 ✅

- [ ] **退订选项**：通话中提供退订选项（"如不需要请回复 T"）
- [ ] **黑名单管理**：客户要求不再联系后，加入黑名单不再外呼
- [ ] **退订生效**：退订请求 24 小时内生效

### 2.3 话术合规 ✅

- [ ] **不承诺结果**：禁止"保证胜诉"、"100% 拿到赔偿"等承诺
- [ ] **不虚假宣传**：不虚构"法院合作"、"法官认识"等关系
- [ ] **不恐吓误导**：禁止"不找律师就输了"等恐吓性话术
- [ ] **不贬低同行**：不诋毁其他律所或律师

---

## 三、通话录音合规

### 3.1 录音告知 ✅

- [ ] **明示录音**：开场白告知"通话可能录音"（部分省份要求）
- [ ] **录音标识**：系统中明确标识已录音的通话

### 3.2 录音存储 ✅

- [ ] **存储期限**：录音保存≥6 个月（法律纠纷追溯期）
- [ ] **安全存储**：录音文件加密存储，防止篡改
- [ ] **访问日志**：记录谁在何时访问了录音

### 3.3 录音使用 ✅

- [ ] **内部使用**：录音仅用于质量监控和纠纷处理
- [ ] **不对外公开**：未经客户同意不公开录音
- [ ] **客户调取**：客户可要求调取其通话录音

---

## 四、微信营销合规

### 4.1 好友添加 ✅

- [ ] **身份说明**：好友申请备注清楚身份和来意
- [ ] **不频繁添加**：避免短时间大量添加好友（防封号）
- [ ] **尊重拒绝**：客户拒绝后不再重复添加

### 4.2 消息发送 ✅

- [ ] **不过度打扰**：避免频繁发送消息（建议≤2 次/周）
- [ ] **内容合规**：不发送虚假、夸大、违规内容
- [ ] **退订选项**：提供"不再接收消息"的选项

---

## 五、广告法合规

### 5.1 宣传内容 ✅

- [ ] **不绝对化**：禁止"最好"、"第一"、"顶级"等绝对化用语
- [ ] **不虚假**：不虚构成功案例、律师资历
- [ ] **不比较**：不与其他律所直接比较

### 5.2 案例展示 ✅

- [ ] **客户同意**：展示案例需经客户同意
- [ ] **隐去隐私**：隐去客户姓名、电话等隐私信息
- [ ] **不承诺类似结果**：注明"案例仅供参考，不构成承诺"

- [ ] **培训记录**：保存员工培训记录
- [ ] **投诉记录**：保存客户投诉及处理记录

## 八、违规处罚风险

### 8.1 可能面临的处罚

| 违规行为 | 处罚依据 | 处罚力度 |
|----------|----------|----------|
| 骚扰电话 | 《治安管理处罚法》 | 警告、罚款 |
| 侵犯个人信息 | 《个人信息保护法》 | 最高 5000 万或营业额 5% |
| 虚假宣传 | 《广告法》 | 罚款 20-100 万 |
| 冒充公检法 | 《刑法》 | 刑事责任 |

### 8.2 风险防范 ✅

- [ ] **定期自查**：每月进行一次合规自查
- [ ] **及时整改**：发现问题立即整改
- [ ] **购买保险**：考虑购买职业责任险
